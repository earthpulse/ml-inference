What is ML-Inference API?

A powerful, production-ready API that automatically downloads ML models from EOTDL and performs inference on your data. Built for scalability, security, and performance with support for both online and batch processing.

Quick Start

Get started in seconds with Docker:

# CPU inference
docker run -p 8000:80 -e EOTDL_API_KEY=<your_key> earthpulseit/ml-inference

# GPU inference
docker run --gpus all -p 8000:80 -e EOTDL_API_KEY=<your_key> earthpulseit/ml-inference-gpu

Then access the API at http://localhost:8000. You can get your EOTDL API key for free by signing up at EOTDL and creating a new key in your profile.

Run Inference

Perform inference on a model (e.g., RoadSegmentationQ2):

Using curl:

curl -X POST "http://localhost:8000/RoadSegmentationQ2" \
  -F "image=@path/to/your/image.jpg"

Using Python:

import requests

url = "http://localhost:8000/RoadSegmentationQ2"
with open("image.jpg", "rb") as f:
    response = requests.post(url, files={"image": f})

# For segmentation models, save the output mask
with open("output_mask.tiff", "wb") as f:
    f.write(response.content)

Depending on the model, you may need to preprocess the inputs and outputs in a particular way. Look at the model documentation for more details.
